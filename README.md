# أثر توزيع الأخطاء العشوائية على الحجم الأمثل للعينة في نماذج الانحدار اللامعلمي

دراسة محاكاة مونت كارلو لأثر توزيع الخطأ العشوائي (طبيعي، أسي، جاما، t(3)، كوشي)
على حجم العينة اللازم لتقدير دقيق بطريقتي الانحدار النووي (Nadaraya-Watson)
والمقدّر القوي (الوسيط المرجَّح).

## المحتويات

- `code/` — كود Python الأساسي (المحاكاة، التحليل، الأشكال). انظر `code/README.txt`.
- `spss/` — كود SPSS (نسخة تعليمية مبسطة + تحليل نتائج مُصدَّرة من Python).

## طريقة التشغيل

راجعي `code/README.txt` لتفاصيل التشغيل الكامل بلغة Python
(الإصدارات: Python 3.12، numpy 2.4، scipy 1.17، pandas، matplotlib).

## قابلية إعادة الإنتاج

البذرة العشوائية ثابتة (20260918) في جميع الأكواد، فالنتائج قابلة لإعادة الإنتاج بدقة.
